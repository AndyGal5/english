How to Play: "Tag Question Challenge"

This game is designed to help students practice grammar using tag questions in a fun, interactive way!

  • Work in teams or individually.
  • Click a cell on the board to receive a tag question.
  • Type your answer and submit it.
  • If your answer is correct, you earn the points shown on the tile.
  • If incorrect, no points are awarded and the correct answer is shown.
  • Try to collect as many points as possible before time runs out or all questions are used.
  • Each question is only available once.
  • Practice using tag questions with different tenses and sentence types.

Tip: Be careful with affirmative/negative structure and auxiliary verbs!
